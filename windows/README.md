# 快捷证件照 · Windows 桌面版（v2.0.0）

与 Android v2.0.0 **算法同源**的 Windows 桌面程序，完美复刻单张/批量证件照制作能力，并针对电脑使用习惯做了全面优化。基于 Python 3.8 + PyQt5，绿色便携、**无需安装、不联网、照片全程本地处理**。

## 下载与运行

1. 到 [Releases](https://github.com/donghuaigu123/QuickIDPhoto/releases) 下载 `QuickIDPhoto-Windows-v2.0.0.zip`。
2. 解压到任意目录（建议路径不含中文以外的特殊字符）。
3. 双击根目录的 **`快捷证件照.exe`** 启动。

**系统要求**：Windows 7 SP1 x64 / 8 / 8.1 / 10 / 11（64 位）。**不支持 32 位系统**。VC++ 运行库已内置，无需额外安装。

## 桌面端专属优化

- **三栏布局**：左侧照片队列、中间大图预览、右侧五个参数页签，宽屏下互不遮挡。
- **目录导入可视化选择**：选择照片文件夹后以缩略图网格展示全部照片，可勾选/反选/筛选/排序/包含子文件夹，双击切换勾选，一次导入多张。
- **导出目录自由选择**：底部目录框可浏览或手动输入，自动记忆上次位置；保存后显示实际 KB 并可直接打开所在文件夹。
- **预览交互**：滚轮缩放、拖动平移、双击适应窗口、三分构图参考网格。
- **快捷键**：`Ctrl+O` 导入文件、`Ctrl+Shift+O` 导入目录、`Ctrl+S` 保存当前、`Ctrl+E` 批量导出、`Delete` 移除选中。
- **拖拽导入**：把文件或文件夹直接拖入窗口即可导入。
- **流畅不卡顿**：后台线程渲染 + 220ms 防抖 + 过期结果丢弃。

## 功能（与 Android v2.0.0 一致）

- 人脸自动构图：最大人脸检测，脸部占比/头顶留白/水平位置可调，拖动与缩放微调
- 发丝级抠图换底：同一份 `hivision_modnet.onnx`，整图直接拉伸推理、无阈值化引导滤波、背景洪泛清理；颜色预设 + 可视化取色 + 透明 PNG + 渐变背景
- 美颜精修：总强度 + 平滑/提亮/红润/锐化 + 快捷预设
- 光影调色：亮度/对比度/饱和度/色温/色调/阴影/高光 + 自动白平衡
- 高清输出：Lanczos-3 重采样，1x/2x/3x 放大，DPI 元数据写入
- 文件大小限制：JPG 质量按目标 KB 自动二分压缩
- 排版照：六寸/五寸/A4/3R/4R，300DPI，自定义排版底色与裁切辅助线
- 批量制作与预览：与单张相同的全部设置，逐张预览，一键批量导出

## 与 Android 版的差异

Windows 端没有 ML Kit，人脸检测改用内置 OpenCV 级联检测器，抠图第二引擎用 MODNet 高置信核心替代；检测失败时可用构图滑块手动微调，核心功能不受影响。其余算法（MODNet 输入/后处理、美颜、调色、缩放、编码、排版）与 Android v2.0.0 完全一致。

## 源码与二次开发

`windows/source/` 为完整 Python 源码。本地运行需 Python 3.8 与依赖：

```bash
pip install "numpy==1.23.5" "PyQt5==5.15.9" "PyQt5-sip==12.12.0" \
  "opencv-python-headless==4.8.1.78" "onnxruntime==1.13.1" "Pillow==9.5.0"
# 模型文件复用仓库已有资源，复制到源码资源目录：
cp app/src/main/assets/hivision_modnet.onnx windows/source/resources/
cd windows/source && python main.py
```

源码结构：

```text
windows/source/
├── main.py                 # 程序入口
├── engine/
│   ├── models.py           # 数据模型：规格、设置、预设
│   ├── crop.py             # 人脸构图计算
│   ├── matting.py          # MODNet ONNX 抠图
│   ├── processor.py        # 抠图/换底/美颜/调色/锐化主引擎
│   ├── layout.py           # 排版照生成
│   └── imageio.py          # 保存、DPI、KB 限制
├── ui/
│   ├── main_window.py      # 三栏主窗口与批量流程
│   ├── theme.py            # 统一配色与样式
│   ├── widgets.py          # 预览控件、滑块、Chip 等
│   ├── pickers.py          # 目录缩略图可视化选择器
│   └── workers.py          # 后台渲染/导出线程
└── resources/              # OpenCV 人脸级联 + MODNet 模型
```
