# 快捷证件照 Windows 版 v2.1.0

功能与 Android v2.1.0 完全同源的桌面版本，**照片全部在本机处理，不上传任何服务器**。
采用便携化封装：无需安装 Python、无需联网，解压即用；支持 **Windows 7 SP1 64 位**及更高版本。

## 一、快速开始

1. 将整个 `QuickIDPhoto-Windows-v2.1.0` 文件夹复制到本机任意目录（路径建议不要包含特殊字符）。
2. 双击根目录的 **`快捷证件照.exe`** 启动。
3. 在右侧「照片队列」点击 **添加照片** 或 **添加目录**；也可以直接把照片/文件夹拖进窗口。
4. 调整右侧五个页签中的参数，中间预览区实时更新。
5. 在底部选择 **导出目录**（默认 `图片\快捷证件照`），点击 **批量导出** 或 **保存当前**。

> 若杀毒软件提示，请选择"允许/信任"。首次启动需加载 ONNX 模型，约 1–3 秒属正常现象。

## 二、目录导入与可视化勾选（桌面版新增）

- 点击顶部 **导入照片目录** 或左侧 **添加目录**，先选择照片所在文件夹。
- 弹窗内以**缩略图网格**展示该目录下的全部照片，每张均可勾选/取消。
- 支持：
  - 按文件名筛选
  - 按名称 / 修改时间 / 文件大小排序
  - 包含子文件夹
  - 全选 / 全不选 / 反选
  - 双击缩略图快速切换勾选
- 勾选完成后点击 **加入处理列表**，照片进入左侧队列，可逐张预览与统一调参。

## 三、功能对照（与 Android v2.1.0 一致）

| 页签 | 功能 |
|---|---|
| 智能构图 | 15 种证件照规格 + 自定义像素/DPI；脸部占比、头顶留白、水平位置；重新检测人脸、重置构图、三分线；左旋/右旋/水平镜像 |
| 抠图换底 | MODNet 本地抠图 + 深核心融合 + 背景洪泛清理；保留原背景、6 种纯色、透明 PNG、4 款渐变及自定义双色渐变；边缘柔化 / 轮廓收缩扩展 / 发丝细节三滑块 |
| 美颜精修 | 自然 / 清透 / 精致预设；总强度、皮肤平滑、肤色提亮、气色红润、细节锐化（锐化独立于总强度） |
| 光影调色 | 亮度、对比度、饱和度、色温、色调、阴影、高光；自动白平衡、自然增强、全部归零 |
| 输出排版 | 1x / 2x / 3x Lanczos-3 高清放大；JPG / PNG；JPG 质量与文件大小上限（适配 20–200KB 报名系统）；六寸/五寸/A4/3R/4R 300DPI 排版照与裁切线 |

批量模式下所有参数统一应用到队列中每一张照片，并逐张按最高分辨率重新渲染导出。

## 四、桌面端专属优化

- **三栏布局**：左侧队列、中间大图预览、右侧参数，符合电脑操作习惯；宽屏下各区域互不遮挡。
- **实时预览**：参数变化后 220ms 防抖重渲染，后台线程执行，界面不卡顿；过期结果自动丢弃。
- **预览操作**：滚轮缩放、按住拖动平移、双击适应窗口、100% 原尺寸按钮。
- **键盘快捷键**：

  | 快捷键 | 功能 |
  |---|---|
  | `Ctrl+O` | 导入照片（可多选） |
  | `Ctrl+Shift+O` | 导入照片目录并可视化勾选 |
  | `Ctrl+S` | 保存当前照片 |
  | `Ctrl+E` | 批量导出全部照片 |
  | `Delete` | 从队列移除选中照片 |
  | `+` / `-` | 预览放大 / 缩小 |

- **拖放支持**：直接把照片文件或文件夹拖到窗口即可导入。
- **记忆设置**：导出目录、上次访问目录、窗口位置自动保存，下次启动沿用。
- **结果反馈**：保存后显示实际文件大小，并提供"打开所在文件夹"；批量完成显示成功/失败数量并可直接打开导出目录。

## 五、系统要求与兼容性

- 操作系统：Windows 7 SP1 64 位 / Windows 8 / 8.1 / 10 / 11（**不支持 32 位系统**）。
- 建议 Windows 7 已安装系统更新（含通用 CRT 更新 KB2999226）。
- 内存建议 4GB 及以上；批量处理大量高清照片时内存占用会升高。
- 运行时与模型均已内置：Python 3.8.10、PyQt5 5.15.9、OpenCV 4.8、ONNX Runtime 1.13.1、hivision_modnet.onnx。

## 六、常见问题

- **双击 exe 没反应**：请确认整个文件夹完整、未只复制 exe；检查 `runtime` 与 `app` 目录是否同级存在。
- **提示缺少 DLL**：确认 `runtime\python` 下的 `msvcp140*.dll`、`vcruntime140*.dll` 存在；Win7 请先安装系统更新。
- **人脸没检测出来**：复杂背景或侧脸可能漏检，可用「重新检测」；仍失败时用脸部占比/头顶留白/水平位置滑块手动微调，不影响抠图与输出。
- **抠图边缘不理想**：优先调「发丝细节保留」与「边缘柔化」，"轮廓收缩/扩展"只影响半透明边缘带。
- **导出的 JPG 太大**：在「输出排版」页设置"文件大小上限"（如 200 KB），保存时会自动二分压缩到限制内。

## 七、v2.1.0 更新说明

- **修复按钮文字看不清**：旧版样式表参数错位，导致普通按钮文字被渲染成浅灰白色（白底上几乎不可见）、边框变成深色。本版改用命名占位符重写样式，所有按钮文字统一为高对比深色（#1E293B），悬停/选中态同步增强。
- **全面美化**：分区标题增加主色竖线、选项按钮与页签强化选中态、列表选中改为实心主色配白字、整体配色更醒目统一。
- **稳定性修复**：退出程序时后台线程会被正确取消并等待结束，杜绝“线程仍在运行被销毁”导致的退出崩溃。
- **性能与细节修复**：高倍缩放时棋盘背景只绘制可见区域避免卡顿；自定义规格不再重复累积条目；文件对话框路径处理更稳健。
